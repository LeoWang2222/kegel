# 凯格尔运动小助手 · 精修版

一个可添加到 iPhone 主屏幕的轻量 PWA。暖白、松绿和蜜桃色，专注男性盆底肌训练的节奏引导与记录。

**直接使用：https://leowang2222.github.io/kegel/**

## 在 iPhone 上使用

1. 用 Safari 打开上面的地址。
2. 点击分享，选择「添加到主屏幕」。
3. 从主屏幕图标进入。首次联网加载并缓存完成后，练习可离线使用。

已有主屏幕图标可以继续使用。新版会在联网打开时检查更新；若仍显示旧版，关闭旧页面后重新打开。无需清除浏览器数据。

## 这一版的变化

### 5.2 · 给练习一点音乐

- 新增原创合成氛围音乐「微光」，柔和和弦与稀疏铃音，24 秒无缝循环，无人声，不需要音乐账号或外部下载。
- 默认关闭。在训练页点音乐按钮，或在「我的 → 练习时的音乐」开启；音量默认 35%，开关和音量在本机保存，与阶段提示音独立。
- 只在训练中播放，暂停淡出、继续淡入并接续音乐位置；退出或完成停止，切到后台立即静音。刷新不会自行播放，继续练习后再启动。
- 音乐由设备本地生成，离线可用；不修改已有训练时长、每日目标和记录。

### 5.1 · 更轻松地跟随和继续

- 首页可选「按住训练」与「自动引导」。自动模式先准备 3 秒，再按已有收紧、放松时长交替提示。
- 自动保存未完成组数的进度；刷新、关闭或离开页面后，可从首页继续或重新开始。恢复前先准备，未完成收紧重新计时，尚未完成的放松重新计足。
- 自动模式切到后台立即暂停；不会在后台补算训练次数，也不会一次跳过多个阶段。
- 外观支持跟随系统、浅色和深色，偏好保存在本机。提高小字可读性，微调按压回弹，完成页增加短暂的波纹庆祝。
- 记录页优先显示本周练习天数；原有训练时长、每日目标和历史记录保持。

- 首页突出今日进度与训练入口，配有统一的线条图标和重新绘制的 SVG 蜜桃。
- 按钮轻压反馈、长按形变、连续进度环；减少跳动和重复提示。
- 按住模式保持收紧—松手—放松流程；自动模式跟随计时切换。两种模式都在最后一次放松结束后计入一组。
- 暂停和恢复；切到后台、触摸取消时自动暂停。本组已完成次数保留，未完成收紧重新开始，休息阶段恢复完整放松时长。
- 本周概览、月历、最近记录、独立完成小结。
- 可调每日目标、收紧和放松时长，默认静音，阶段提示音可选。
- 保留旧版存储键与已有组数、达标记录；首次迁移自动备份原始旧数据。
- 计划开始日期固定，跨日统计按本地日期归档。
- 安全区域适配、键盘长按、减少动态效果设置、离线缓存及更新保护。

## 隐私与用途

记录与未完成练习的检查点仅保存在当前浏览器的 localStorage，不上传。更换设备、浏览器或清除网站数据后不会自动恢复。恢复的练习保留该组原先的模式和时长；设置修改作用于新的一组。建议只在一个页面练习，另一页面更新状态时当前页面会返回首页。

这是网页应用，不是 App Store 原生安装包。两种模式都不能检测盆底肌发力；自动模式记录的是引导计时次数。训练不保证硬度、持久力或特定时间内的效果。指导内容参考 [NIDDK](https://www.niddk.nih.gov/health-information/urologic-diseases/kegel-exercises) 与 [Mayo Clinic](https://www.mayoclinic.org/healthy-lifestyle/mens-health/in-depth/kegel-exercises-for-men/art-20045074)。

## 本地打开与预览

可以直接双击本目录的 index.html 使用。请保留同目录的 app.js、styles.css、refinements.css 和图片文件。直接打开的本地文件与线上网址属于不同的存储空间，记录不互通。

需要 Python 3。在本目录运行：

```sh
python -m http.server 8766 --bind 127.0.0.1
```

打开 http://127.0.0.1:8766 可预览安装与离线缓存功能；这些功能仅用于 HTTP/HTTPS 访问。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| index.html | 页面与语义化结构 |
| styles.css | 视觉、布局和动效 |
| refinements.css | 5.1 手感、小字、恢复入口与深色主题 |
| music.mjs | 原创氛围音乐合成、循环和独立淡入淡出 |
| app.mjs | 界面交互、持久化、音频、PWA 更新 |
| app.js | 自动生成的普通脚本，兼容双击 HTML 与线上访问 |
| scripts/build.mjs | 无依赖构建脚本，修改模块源文件后运行 npm run build |
| core.mjs | 可测试的训练状态与数据逻辑 |
| peach.svg / favicon.svg | 吉祥物和图标源文件 |
| apple-touch-icon.png / icon-512.png | 主屏幕图标 |
| sw.js / manifest.webmanifest | 离线缓存、安装配置 |
| tests/core.test.mjs | 核心逻辑测试 |

部署仍使用 GitHub Pages：main 分支根目录。修改模块源文件后先执行 npm run build，提交生成的 app.js。更新任何已缓存的应用文件时，必须递增 sw.js 的 CACHE 版本，保证 HTML、样式与脚本作为完整版本更新。
