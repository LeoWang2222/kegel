# 凯格尔运动小助手 · 精修版

一个可添加到 iPhone 主屏幕的轻量 PWA。暖白、松绿和蜜桃色，专注男性盆底肌训练的节奏引导与记录。

**直接使用：https://leowang2222.github.io/kegel/**

## 在 iPhone 上使用

1. 用 Safari 打开上面的地址。
2. 点击分享，选择「添加到主屏幕」。
3. 从主屏幕图标进入。首次联网加载并缓存完成后，练习可离线使用。

已有主屏幕图标可以继续使用。新版会在联网打开时检查更新；若仍显示旧版，关闭旧页面后重新打开。无需清除浏览器数据。

## 这一版的变化

- 首页突出今日进度与训练入口，配有统一的线条图标和重新绘制的 SVG 蜜桃。
- 按钮轻压反馈、长按形变、连续进度环；减少跳动和重复提示。
- 完整的收紧—松手—放松流程，最后一次放松结束才计入一组。
- 暂停和恢复；切到后台、触摸取消时自动暂停。本组已完成次数保留，未完成收紧重新开始，休息阶段恢复完整放松时长。
- 本周概览、月历、最近记录、独立完成小结。
- 可调每日目标、收紧和放松时长，默认静音，阶段提示音可选。
- 保留旧版存储键与已有组数、达标记录；首次迁移自动备份原始旧数据。
- 计划开始日期固定，跨日统计按本地日期归档。
- 安全区域适配、键盘长按、减少动态效果设置、离线缓存及更新保护。

## 隐私与用途

记录仅保存在当前浏览器的 localStorage，不上传。更换设备、浏览器或清除网站数据后不会自动恢复。未完成的一组仅在当前页面内保存，刷新或关闭页面后不保留。

这是网页应用，不是 App Store 原生安装包。屏幕按压用于跟随节奏，不能检测盆底肌发力。训练不保证硬度、持久力或特定时间内的效果。指导内容参考 [NIDDK](https://www.niddk.nih.gov/health-information/urologic-diseases/kegel-exercises) 与 [Mayo Clinic](https://www.mayoclinic.org/healthy-lifestyle/mens-health/in-depth/kegel-exercises-for-men/art-20045074)。

## 本地预览

需要 Python 3。在本目录运行：

```sh
python -m http.server 8766 --bind 127.0.0.1
```

打开 http://127.0.0.1:8766 。请通过 HTTP 预览，不要直接双击 HTML（浏览器会限制 ES 模块）。

## 检查

需要 Node.js，无运行时 npm 依赖。

```sh
npm test
npm run check
```

11 项自动测试覆盖数据迁移、跨日归档、连续达标、计划日期、设置边界、提前松手、计时边界、暂停恢复以及完成整组。

浏览器已检查 393×852 和 360×740 手机尺寸下的布局、导航、暂停恢复、提前松手、设置加减、日历切换、安装说明与离线启动。通过停止本地服务器后重新加载，验证首页和训练页仍可打开。实际 iPhone 17 的触感、音频策略、主屏幕安全区域和高刷新率表现仍需真机体验。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| index.html | 页面与语义化结构 |
| styles.css | 视觉、布局和动效 |
| app.mjs | 界面交互、持久化、音频、PWA 更新 |
| core.mjs | 可测试的训练状态与数据逻辑 |
| peach.svg / favicon.svg | 吉祥物和图标源文件 |
| apple-touch-icon.png / icon-512.png | 主屏幕图标 |
| sw.js / manifest.webmanifest | 离线缓存、安装配置 |
| tests/core.test.mjs | 核心逻辑测试 |

部署仍使用 GitHub Pages：main 分支根目录。更新任何已缓存的应用文件时，必须递增 sw.js 的 CACHE 版本，保证 HTML、样式与模块作为完整版本更新。
